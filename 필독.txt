elastic_api_standard 실행 시 사용하는 환경변수 정리
=====================================================
(작성일: 2026-10-22 / 대상: com.rayful.elastic.api 전체 + 병합된 com.rayful.elastic.api.loader)


1. 반드시 있어야 기동되는 것 (fail-fast, 모든 프로파일 공통)
-----------------------------------------------------
환경변수                     | 용도                                        | 비고
JASYPT_ENCRYPTOR_PASSWORD    | application-*.yml 의 ENC(...) 복호화 키      | JasyptAesConfig 가 System.getenv() 로 직접 읽음.
                             |                                             | 없거나 빈 값이면 IllegalStateException 으로 기동 실패.
                             |                                             | k8s 프로파일처럼 ENC() 가 전혀 없어도 여전히 필요(코드가
                             |                                             | 무조건 검증하기 때문).
SECURITY_AES_KEY             | SecurityModule 의 AES-256 암복호화 키        | 길이가 16, 24, 32바이트 중 하나여야 함.
                             |                                             | 아니면 IllegalStateException 으로 기동 실패.


2. 프로파일(spring.profiles.active)별로 필요한 것
-----------------------------------------------------
프로파일 | 환경변수        | 기본값         | 비고
local    | ES_PASSWORD    | changeme       | 없어도 기동은 됨 (기본값 사용)
dev      | DB_USERNAME    | (없음)         | 안 넣으면 빈 문자열로 들어감 (MariaDB 접속 실패 가능)
dev      | DB_PASSWD      | (없음)         | 위와 동일
dev      | KEY_STORE_PWD  | (없음)         | ES 접속용 키스토어(elastic.jks) 비밀번호
prod     | (없음)         | -              | DB/ES 자격증명이 전부 ENC(...) 또는 하드코딩 — 1번 항목만 있으면 됨
k8s      | (없음)         | -              | ES는 클러스터 내부 서비스로 접속, DB 자동설정 자체를 꺼서 불필요

프로파일 선택:
환경변수                | 용도
SPRING_PROFILES_ACTIVE | local/dev/prod/k8s 중 선택. 안 주면 application.yml 기본값(local)로 동작
                        | (start.sh 는 --spring.profiles.active=$SERVER_ENV 로 명시 지정하므로 그쪽이 우선)


3. 병합된 로더(com.rayful.elastic.api.loader) 쪽
-----------------------------------------------------
새로 추가한 환경변수는 없음. 기존 elasticsearch.* 설정(2번 표와 동일 계열)에 얹혀 있고,
local 프로파일 기준 ES_PASSWORD 가 유일하게 관련 있는 변수.
(자세한 설정 위치는 DESIGN.md 5절 참고)


4. 배포 스크립트(search_api/bin/*.sh) 내부 변수
-----------------------------------------------------
"환경변수"처럼 보이지만 실제로는 setEnv.sh 안에서 직접 export 되는 값입니다.
외부에서 주입하는 구조가 아니라, 배포 경로/힙 크기가 다르면 setEnv.sh 자체를 수정해야 합니다.

변수          | 기본값(스크립트에 하드코딩)
API_HOME      | /DATA/app/search_api
JAVA_HOME     | /DATA/jdk-17
JAVA_HEAP     | -Xms1024m -Xmx1024m
SERVER_ENV    | dev
WAR_FILE_PATH | API_HOME 기준 파생 ($API_HOME/elastic_api_standard.war)
DEPLOY_DIR    | API_HOME 기준 파생 ($API_HOME/deploy)

참고: SERVER_SSL_PATH, ELSTICE_SSL_PATH 는 start.sh 안에 "주석 처리된" 줄에만 등장 —
      현재 활성화된 실행 커맨드에서는 사용되지 않습니다.


5. 운영 기동 전 최소 체크리스트
-----------------------------------------------------
[ ] JASYPT_ENCRYPTOR_PASSWORD 설정 (모든 환경 공통, 필수)
[ ] SECURITY_AES_KEY 설정 (모든 환경 공통, 필수, 16/24/32바이트)
[ ] SPRING_PROFILES_ACTIVE 로 프로파일 선택 (또는 setEnv.sh 의 SERVER_ENV)
[ ] 선택한 프로파일에 해당하는 2번 표의 변수 추가 설정
    - local: ES_PASSWORD (선택)
    - dev:   DB_USERNAME, DB_PASSWD, KEY_STORE_PWD (필수)
    - prod:  추가 없음
    - k8s:   추가 없음
[ ] setEnv.sh 의 API_HOME/JAVA_HOME/JAVA_HEAP 이 실제 배포 서버 환경과 맞는지 확인
